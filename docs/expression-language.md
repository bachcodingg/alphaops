# Expression language

Alphas are written in a small, Fast-Expression-style language. An expression is evaluated
once over the whole history and produces a **date Ã— symbol matrix**: the alpha value of each
stock on each day. The simulator turns that matrix into a long/short book.

```text
rank(-ts_delta(close, 5))                                   # one expression
move = -ts_sum(returns, 5); rank(move) * (volume > adv20 / close ? 1.5 : 1)   # statements
```

## Syntax

| Construct | Example |
|---|---|
| Arithmetic | `+ - * / ^` (division by zero gives NaN, never inf) |
| Comparison | `< <= > >= == !=` â†’ 1.0 / 0.0 (NaN if an input is NaN) |
| Logic | `&&`, `\|\|`, `!x` |
| Conditional | `cond ? a : b` (same as `if_else(cond, a, b)`) |
| Variables | `name = expr;` and the last statement is the alpha |
| Keyword args | `scale(x, scale=2)`, `winsorize(x, std=3)` |
| Constants | numbers, `nan`, `true`, `false` |

Windows (`d`) must be integer constants in `[1, 1000]`. Rolling operators need at least
75% of the window to be present, so a single missing bar (e.g. a quarantined row) does not
blank out `d` days of signal.

**No look-ahead by construction.** Every `ts_*` operator only uses the current and past
rows, and there is no negative delay. `tests/test_no_lookahead.py` checks this by
perturbing all data after a cutoff date and asserting results before it are unchanged.

| Operator | Category | Description |
|---|---|---|
| `ts_delay(x, d)` | time-series | value d days ago |
| `ts_delta(x, d)` | time-series | x - ts_delay(x, d) |
| `ts_mean(x, d)` | time-series | rolling mean |
| `ts_sum(x, d)` | time-series | rolling sum |
| `ts_std(x, d)` | time-series | rolling standard deviation |
| `ts_min(x, d)` | time-series | rolling minimum |
| `ts_max(x, d)` | time-series | rolling maximum |
| `ts_rank(x, d)` | time-series | percentile of today's value within the window |
| `ts_zscore(x, d)` | time-series | (x - ts_mean) / ts_std |
| `ts_av_diff(x, d)` | time-series | x - ts_mean(x, d) |
| `ts_scale(x, d)` | time-series | (x - ts_min) / (ts_max - ts_min) |
| `ts_corr(x, x2, d)` | time-series | rolling correlation |
| `ts_cov(x, x2, d)` | time-series | rolling covariance |
| `ts_decay_linear(x, d)` | time-series | linearly weighted moving average (today weighs most) |
| `ts_argmax(x, d)` | time-series | days since the window maximum |
| `ts_argmin(x, d)` | time-series | days since the window minimum |
| `ts_backfill(x, d)` | time-series | forward-fill missing values for up to d days |
| `rank(x)` | cross-sectional | percentile rank across stocks |
| `zscore(x)` | cross-sectional | standardize across stocks |
| `normalize(x)` | cross-sectional | subtract the cross-sectional mean |
| `scale(x, scale=)` | cross-sectional | rescale so sum(|x|) = scale (default 1) |
| `winsorize(x, std=)` | cross-sectional | clip at mean ± std·sd (default 4) |
| `group_neutralize(x, group)` | group | subtract the group mean |
| `group_rank(x, group)` | group | percentile rank in group |
| `group_zscore(x, group)` | group | z-score in group |
| `group_mean(x, group)` | group | group mean |
| `abs(x)` | elementwise | absolute value |
| `log(x)` | elementwise | natural log (NaN for x <= 0) |
| `sqrt(x)` | elementwise | square root (NaN for x < 0) |
| `sign(x)` | elementwise | -1, 0 or 1 |
| `signed_power(x, p)` | elementwise | sign(x) * |x|^p |
| `power(x, x2)` | elementwise | x^y |

| `min(x, x2)` | elementwise | elementwise minimum |

| `reverse(x)` | elementwise | -x |
| `is_nan(x)` | elementwise | 1 where x is missing |

| Field | Description |
|---|---|
| `open` | session open price |

| `dollar_volume` | close * volume (traded value) |
